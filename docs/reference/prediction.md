# Prediction and model checks

Use prior prediction to examine the implications of priors and posterior
prediction to compare replicated and observed answers. Use
`chi_ppp()` for a categorical Pearson check and `log_likelihood()` for
pointwise densities. Match the data and observation units when comparing models.
