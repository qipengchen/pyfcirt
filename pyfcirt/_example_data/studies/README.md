# Study example resources

Load these resources with `pyfcirt.load_example(name, model=..., n_persons=...)`.
Simulation studies default to 100 respondents and store nested 50-, 100- and
500-person cohorts. `include_truth=True` includes the original generating Dataset
in `ExampleData.truth`; it does not simulate or fit a model. Each folder contains the complete design,
constructor options and provenance. `checksums.json` records resource hashes.

## Empirical data: carelessness_big_five

Attribution: Kupffer, Frick and Wetzel, *Detecting Careless Responding in
Multidimensional Forced-Choice Questionnaires*.
Source: https://github.com/rkupffer/ExploratoryAnalysesCRinMFC
Source revision: ea756a6833cdaf73988ca66d2ef109154867f9bb.

These numerical response data are licensed **CC BY 4.0**, separately from
PyFCIRT's code license. The authors' license declaration and attribution are
recorded in `metadata.json`; the complete license is in
`carelessness_big_five/LICENSE-CC-BY-4.0.txt`.

Changes: retain only the Big Five MT triplet columns; replace respondent labels
with source row order; derive known pair comparisons using the authors' lower
rank-is-preferred convention; retain missing comparisons; omit item wording,
demographics and other subtests; attach the TIRT model declaration. Raw numerical
statement ranks are preserved in `ranks_full.csv.gz`. The 50-, 100- and 500-person
files are deterministic subsets of the same 1,169-person cohort.

No ranks are imputed. Block-position statement IDs do not assert undocumented
stimulus sharing across blocks. See `metadata.json` for source hashes and coding
references. Only numerical data and the design are redistributed; the authors'
GPL-licensed analysis code is not included.

## Empirical data: hexaco_triplets

Li et al. (2025), *Mixed-Keying or Desirability-Matching in the Construction of
Forced-Choice Measures?*, https://doi.org/10.1177/10944281241229784.
The source is the authors' five-block, 541-person numerical example distributed
with autoFC 0.2.0.1001. It is not the complete OSF questionnaire or sample.

The numerical data and design retain the source package's **GPL-3** license,
separate from PyFCIRT's source-code license. The complete license, attribution,
source URL and adaptation notice accompany the example. Original numerical
responses and design are preserved as CSV, and the public curation script
regenerates the converted cohorts. See `hexaco_triplets/NOTICE.txt`.

The default cohort has 100 people; 50 and all 541 are also stored. All sizes
retain five triplets and six traits. A value of 1 favors the first statement
named in the source comparison header. The task is MOLE; with three statements
this identifies the complete order. Keying follows `triplet_block_info`.
No ideal-point location directions are inferred from that keying.

## Simulated data

The nine `simulated_*` studies were generated by PyFCIRT's native forward
simulator, without posterior MCMC. Each uses one parameter draw and one complete
500-person response draw. Smaller samples retain the first people and the full
design. All generating values are stored, including cohort-specific Gaussian
utility moments where relevant. Historical model declarations remain in source metadata;
unused unfolding-side fields were removed from dominance-model designs.

`generation.source_generated_data_sha256` identifies the simulator's original
500-person data before this resource annotation; `generated_data_sha256`
identifies each packaged cohort. `source_n_persons`, `n_persons` and
`subset_policy` distinguish cohort sizes. This is teaching data, not evidence
of parameter recovery or sampler convergence. No posterior estimates are bundled.
Generating arrays retain their original names, priors and identification constraints;
they are not current final-parameter points or draws from the new defaults.
The loader uses the caller's explicit model declaration, without inferring it
from historical source labels.
